# SectionHeader

Opens a section inside a window with an `edge` rule, a mono index and kicker, and a bold title.

**Provide:** a `title`. Optional: `index` ("02"), `kicker` ("Selected work") and an `action` element (usually a ghost `Button`).

- Number sections in page order, with two digits. The index is in `signal`, so keep the header inside a window: on the Sage desk, `signal` falls below 4.5:1.
- Write titles in the owner's voice ("Things I built and still maintain"), not as labels ("Projects").
