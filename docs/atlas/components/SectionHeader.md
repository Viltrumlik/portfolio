# SectionHeader

Opens a section inside a window with a dashed `edge` rule, a `// 02 · KICKER` line and a glowing VT323 title that decodes from random glyphs when it scrolls into view.

**Provide:** a `title`. Optional: `index` ("02"), `kicker` ("Selected work") and an `action` element (usually a ghost `Button`).

- Number sections in page order, with two digits. The index is in `signal`.
- Write titles in the owner's voice ("Things I built and still maintain"), not as labels ("Projects").
