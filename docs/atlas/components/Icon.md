# Icon

The Atlas glyph set: 18 line icons on a 24px grid with a 1.5px stroke, drawn in `currentColor`.

**Provide:** `name` (one of `Icon.names`), an optional `size` (14, 16, 18 or 20), and a `title` when the icon is the only thing carrying meaning. Without a `title`, the icon is hidden from assistive tech.

- Use 14 in badges and meta rows, 16 in buttons and lists, and 18–20 in search fields.
- Color comes from the parent's `color`. Don't set a fill.
- Don't use emoji in place of a glyph. For a glyph that isn't here, draw it on the same grid and stroke, or take it from Lucide.
